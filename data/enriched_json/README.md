# EUR-Lex Retrieval Dataset (EUR-LexRD)

This GitHub repository contains the code, configuration files, documentation, and small examples for the **EUR-Lex Retrieval Dataset (EUR-LexRD)**.

The complete dataset is too large to host directly on GitHub. The full versioned dataset is hosted in the university data repository.

## Full Dataset

The complete dataset is available here:

- **Dataset repository:** https://rdr.kuleuven.be/dataset.xhtml?persistentId=doi:10.48804/TK4IER
- **DOI:** https://doi.org/10.48804/TK4IER
- **Dataset version:** v1.0.0

Please cite the EUR-LexRD research paper when using this dataset.
